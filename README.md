### Hi there, I'm Jonas 👋

I'm a Product Engineer based in **Portugal 🇵🇹**. I bridge the gap between high-level product development and low-level systems programming.

I focus on **Developer Experience (DX)** and **High-Performance** architecture.

Currently, I'm building specialized platforms for motorsport and high-performance developer tooling.

---

### 🚀 What I'm Shipping

* **[Apex Scout](https://apexscout.app)** 🏎️
    * Building the ultimate track-day companion and motorsport event platform.
    * *Stack:* Laravel, Inertia.js, React, Tailwind, MySQL.

* **[LaraMux](https://github.com/jonaspauleta/laramux)** 🦀
    * A Terminal UI (TUI) process manager for Laravel, written in Rust.
    * Solves the "tab fatigue" problem by running Serve, Vite, Reverb, and Queues in a single binary.
    * *Stack:* Rust, Tokio, Ratatui.
